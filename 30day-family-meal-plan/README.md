# 30天低碳水家庭菜谱计划

一个为四川江西口味家庭设计的30天低碳水健康菜谱系统。**简单易做、好吃、健康**。

## 🎯 项目亮点

- **30天完整菜谱**：每天三餐，科学搭配，避免重复
- **低碳水设计**：符合现代健康饮食理念，家人减肥利器
- **四川江西口味**：麻婆豆腐、回锅肉、水煮鱼、泡椒等经典菜肴
- **全家适用**：早餐温暖，午餐扎实，晚餐清淡，小孩易接受
- **快手菜为主**：大部分菜肴15-30分钟快速上桌
- **关键点指导**：每道菜都标注了烹饪要点，新手也能做得好吃
- **营养数据**：每餐都标注碳水、蛋白质、脂肪含量

## 📊 营养特色

| 指标 | 目标值 |
|------|------|
| 碳水比例 | 35-40% |
| 蛋白质比例 | 30-35% |
| 脂肪比例 | 25-30% |
| 每日热量 | 2000-2200 cal |

**低碳水策略**：
- 米饭减到半碗或三分之一碗
- 用清汤替代油腻汤底
- 增加蛋白质食物（鸡、鱼、豆腐、鸡蛋）
- 增加纤维蔬菜（青菜、冬瓜、豆芽）

## 👨‍🍳 烹饪关键点速查

### 豆腐
用盐水浸15分钟，防止煮时破碎

### 鱼片
淡盐水腌10分钟去腥；煮时不超2分钟，保持嫩滑

### 牛肉
切片腌10分钟，全程大火快炒，保持嫩度

### 面条
单独煮至八分熟沥干，最后倒汤，面更爽口

### 汤底
- 清水+盐+油：最清
- 鸡汤/高汤：最鲜
- 豆汤：最香

### 红油
干辣椒、花椒、油、盐，小火熬5分钟出香气

### 豆瓣酱
油热后加豆瓣酱炒红油（1-2分钟），是咸香的灵魂

## 💡 使用建议

1. **每周更新购物清单**：根据应用的建议列表采购
2. **灵活调整**：根据冰箱存货和家人口味灵活变通
3. **记录喜好**：发现特别喜欢的菜，记录下来
4. **跟踪效果**：定期称体重，记录进度
5. **小孩适应**：从清汤版开始，慢慢引入咸香味

## 📈 预期效果

- **体重管理**：低碳水+高蛋白，帮助家人管理体重
- **血糖稳定**：减少米饭，血糖波动更平稳
- **能量充足**：高蛋白设计，一整天精力充沛
- **口味满足**：四川江西菜的咸香，比清淡菜更容易坚持
- **全家健康**：大人减肥，小孩也吃得健康

## 🔧 自定义菜谱

想要修改某道菜或替换口味？编辑 `meal_data/meals.py`：

```python
# 修改菜名
"name": "新菜名"

# 修改营养数据
"carbs": 新碳水值,
"protein": 新蛋白质值,
"fat": 新脂肪值,

# 修改烹饪关键点
"key_points": [
    "新的第一个要点",
    "新的第二个要点"
]
```

修改后刷新Streamlit页面即可看到更新。
