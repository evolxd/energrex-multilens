## 🎯 核心特性

### 1️⃣ 完整的30天菜谱

✅ **7×30 = 210道菜**（早午晚各一道）
- 第1-4周：完整的7天循环菜谱，无重复
- 第5周：月底清淡收尾

✅ **每道菜都有**：
- 菜名
- 碳水、蛋白质、脂肪数据
- 3-5个烹饪关键点（解决常见问题）

### 2️⃣ 四川江西口味菜肴

✅ **经典菜**：
- 麻婆豆腐（四川代表）
- 回锅肉（四川国民菜）
- 水煮鱼（四川麻辣菜）
- 宫保鸡丁（四川甜辣菜）
- 泡椒系列（江西开胃菜）
- 腊肠、腊肉系列（江西经典）

✅ **快手菜为主**：
- 95%的菜肴15-30分钟快速上桌
- 适合工作日晚餐
- 周末可炖汤（2小时补囤）

### 3️⃣ 低碳水设计

✅ **每日营养目标**：
| 指标 | 目标值 |
|-----|------|
| 碳水比例 | 35-40% |
| 蛋白质比例 | 30-35% |
| 脂肪比例 | 25-30% |
| 每日热量 | 2000-2200 cal |

✅ **低碳水策略**：
1. 米饭减量到半碗或三分之一碗
2. 用清汤替代油腻汤底
3. 增加蛋白质食物（鸡、鱼、豆腐、鸡蛋）
4. 增加纤维蔬菜（青菜、冬瓜、豆芽）
5. 减少油炸，多用清蒸、白水煮、炖

### 4️⃣ 全家适用

✅ **成人**：
- 低碳水帮助管理体重
- 高蛋白保持饱感和肌肉
- 咸香口味满足欲望

✅ **小孩**：
- 番茄系列温和易接受
- 清汤菜清淡易消化
- 高汤炖菜补气血
- 逐步适应咸香味

✅ **老人**：
- 清汤清淡易消化
- 少油脂、易咀嚼
- 高蛋白帮助维持肌肉量

### 5️⃣ 专业的Streamlit应用

✅ **5个主要页面**：
1. **📅 菜谱日历** - 按周浏览全月菜谱
2. **🍽️ 单日详情** - 详细菜谱+营养+关键点
3. **📊 营养分析** - 目标值、策略、全月统计
4. **🛒 购物清单** - 分类购物清单（蛋白质/蔬菜/调味料/主食）
5. **💡 烹饪贴士** - 常见问题解答（5大类）

✅ **用户友好的设计**：

## 🚀 快速开始

### 选项A：一键启动（推荐）

**Mac/Linux**：
```bash

bash setup.sh
```

**Windows**：
```bash

```

### 选项B：手动启动

```bash
# 1. 进入项目目录
cd 30day-family-meal-plan

# 2. 创建虚拟环境（可选，推荐）
python3 -m venv venv
source venv/bin/activate  # Mac/Linux
# 或
venv\Scripts\activate     # Windows

# 3. 安装依赖
pip install -r requirements.txt

# 4. 启动应用
streamlit run app.py
```

应用会自动打开，访问 `http://localhost:8501`

## 🔧 如何修改菜谱

想要替换某道菜或自定义？编辑 `meal_data/meals.py`：

```python
# 找到相应的day数据
{
    "day": 1,
    "date": "2026-07-26",
    "meals": {
        "breakfast": {
            "name": "菜名",              # 改菜名
            "carbs": 25,                # 改碳水
            "protein": 12,              # 改蛋白质
            "fat": 8,                   # 改脂肪
            "key_points": [             # 改烹饪关键点
                "要点1",
                "要点2"
            ]
        }
    }
}
```

修改后刷新Streamlit页面即可看到更新。

### Q: 怎样导出菜谱为Excel或PDF？

A: 在Streamlit中点击右上角下载按钮，可以导出单日菜谱为PDF。

### Q: 可以改成其他地方的菜吗？

A: 当然可以！编辑 `meal_data/meals.py`，替换菜名和关键点即可。

### Q: 怎样增加菜数或修改天数？

A: 编辑 `meal_data/meals.py` 中的 `MEALS_30_DAYS` 字典，添加新的day数据即可。

### Q: 菜谱可以循环使用吗？

A: 可以！这30道菜设计成无重复，可以连续使用2个月，再从头循环。

### Q: 怎样让团队或家人一起查看？
