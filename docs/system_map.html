VS Code 具体怎么管理

.vscode/ 已经配好了，不用重新搭——打开仓库根目录当 workspace 就能用。

启动整套系统

Ctrl+Shift+P → Tasks: Run Task → "🏠 启动 Dashboard"。这一个任务就够了——5 个页面是同一个 Streamlit 进程，靠左侧导航切，不用分别启动。

跑测试

左侧烧杯图标是 Testing 面板，能看到全部用例逐个点右键单跑；或者 Ctrl+Shift+P → Tasks: Run Task → "🧪 测试：全部"，一次跑完 tests/ 下所有用例。

搞清楚"谁调用谁"

Ctrl+Shift+F 全仓库搜一个函数名（比如 thesis_state_for_ticker），比一个个文件点开读快得多——这是本图里所有"连接线"的验证方法。

看某段代码的来龙去脉

装上推荐的 GitLens 插件后，每一行代码旁边会标最后修改的时间和 commit 信息，鼠标悬停就能看——比翻聊天记录问"这段什么时候写的"快。

Tasks 面板里还有"极速价格刷新"和"命令行审计单只股票"，会弹出输入框让你填股票代码，留空就是全量。
